# Assignment 3: Графовые алгоритмы

Студент: Nurzhan Zholaman
Идентификатор: SE-2515
Язык: Java 17

Реализованы DSU, Краскал, Прим, компоненты сильной связности Косарайю, топологическая сортировка DFS и кратчайшие пути в DAG с восстановлением маршрута.

Инструкции сборки и запуска находятся в README.md. Анализ на английском, доказательства корректности, сложности и замеры находятся в ANALYSIS.md. В tests/ сохранены входные данные, ожидаемые характеристики ответов, фактические результаты и инструменты проверки.

Откройте папку проекта в IntelliJ, выберите JDK 17+, отметьте src/Java как Sources Root и запустите Main. Программа принимает по одному JSON-запросу в строке. Для Windows также предусмотрен Run.ps1.

Полные требования доступны в [исходном шаблоне курса](https://github.com/RZhaniya/daa-assignment-3-graphs).
